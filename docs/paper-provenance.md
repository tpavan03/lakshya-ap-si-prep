## Historical NICL research checks

The 2017 full PDF was retrieved directly from the Prepp publisher CDN. It is
byte-identical to the full PDF mirrored by the historical LST index, while its
first-page title and Testbook solution labels identify the underlying memory
reconstruction. Only the external publisher file is linked; the PDF and its
copyrighted question text are not redistributed in this repository.

A separate FreeJobAlert file titled “NICL AO 2017” was inspected and found to
contain only English questions 1–30. It was **not** counted as another full
paper. Aggregate index claims for 2018/2019, and older links whose file names
refer to NIACL, were not added without matching NICL exam identity and full
paper inspection. The archive does not turn fragmentary or mislabeled links
into extra year coverage.

## Remaining archive records

The previous AP, Kerala and Rajasthan catalogue is retained with its original
provenance labels. This update does not imply every legacy remote link was
revalidated. Records with a full paper, question count and known duration now
support persistent timed answer sheets; only papers with an exact matched key
receive an automatic score. Missing question papers or unknown durations remain
source references. NICL Mains has no verified original/reconstructed full paper
in this release, and its empty state says so instead of inventing a PYQ.

Attempts store absolute timestamps, answers, review flags and the current
question. The timer continues through navigation, reload and background tabs,
and submits at expiry. NICL closes each 20-minute section before opening the
next. Original papers stay separate from authored mocks and custom practice.
