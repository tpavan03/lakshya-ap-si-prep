The expected table is currently unavailable through the configured REST endpoint. It may need the supplied initialization migration or a corrected exposure/schema-cache configuration. No probe row was created.
- Hosted per-user RLS and authenticated save/reload remain **unverified** because the table endpoint is unavailable and no authenticated test session or database-admin connection was available. No fake account, email, or signup was created.
- Existing SQL enables RLS and limits select, insert and update to `auth.uid() = user_id`. This source inspection is not proof that a currently reachable hosted database has those policies installed.
- The remaining backend action is to make `public.user_state` available in the existing project. Check the table in the SQL editor; if absent, apply `supabase/migrations/001_user_state.sql`. If it already exists, verify its public-schema exposure and refresh PostgREST's schema cache. Then repeat read/write isolation and an actual signed-in save/reload check. This does not require a replacement project. Device-only preparation and JSON backups remain available.

The sync hook now gates writes until the current account’s hydration succeeds, rejects stale results from earlier accounts, keeps separate local account caches, preserves work across same-account token refreshes, serializes writes, and retries failed hydration through **Sync now**. Unknown legacy local ownership is not copied into a newly restored account. Existing cloud rows remain authoritative; guest work can seed an empty row only after explicit sign-in, and a previous account’s data can never seed another account.

Initialization, hydration and writes are bounded to 12 seconds so an unreachable backend cannot leave the app indefinitely on its restoration screen. Native callback handling validates the registered scheme and host. AP and NICL progress use the same per-user backend row, with separate exam namespaces inside its payload. Google/email sign-in also checks backend health before starting, so restored service becomes available without a hardcoded outage switch.
