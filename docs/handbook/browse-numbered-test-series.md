# Browse the numbered mock-test series

Open Tests after choosing the exam, stage and stream. Select the intended paper and browse the numbered test cards. The series uses visible cards and pagination rather than hiding the whole selection behind one edition dropdown.

A completed marker refers to a recorded attempt for that edition. It does not certify that a paper is an official previous-year booklet, and it does not mean another numbered simulation contains an entirely unrelated question family. The practice bank includes disclosed generated variants.

Preview the chosen test's paper information before starting. If a saved test is already active, resume or submit that attempt before launching another. This protects the answer sheet from being replaced by an accidental second start. Use custom practice for a shorter targeted set instead of treating a full-paper card as a topic quiz.
